## Detailed Description

```
Ancroo is an AI prompt launcher for your browser. Select text on any page or type input manually, fire an AI prompt, and get results right where you need them. No tab switching. No copy-paste.

SETUP IN SECONDS

Connect to OpenAI, Anthropic, Google Gemini, Ollama, OpenRouter, or any OpenAI-compatible API. Add your API key and start using six built-in actions immediately: Summarize, Translate, Rewrite, Explain, Fix Grammar, and Ask AI.

POINT. PROMPT. DONE.

- Side panel UI — click the extension icon or press Alt+Shift+Y to open
- Text selection — select text on any page, right-click "Run with Ancroo", get AI results
- Hotkeys — trigger actions instantly from any page
- Flexible input — feed selected text (plain or HTML), manual input, or the full page text into your prompt
- Output actions — replace selected text, copy to clipboard, insert before/after, or show in panel
- Execution history — last 50 results stored locally
- Workflow categories — organise actions into named categories with icons; collapsible groups in the side panel
- Backup & restore — export actions and provider settings to a JSON file; import on any device

LLM PROVIDERS

- OpenAI (GPT-4o, GPT-4.1, and more)
- Anthropic (Claude Sonnet 4.6, Claude Haiku 4.5, and more)
- Google Gemini
- Ollama — run models locally on your machine
- OpenRouter — access 200+ models via a single API key
- Any OpenAI-compatible endpoint

ACTION EDITOR

Create your own actions with custom templates, model selection, and input/output configuration. The model browser auto-detects available models from your provider.

PRIVACY

Ancroo collects no analytics, telemetry, or personal data. All settings and history stay in your browser. Data is only sent to LLM providers you configure. See our Privacy Policy for details.

OPEN SOURCE

Ancroo is MIT-licensed and open source. Contributions welcome at https://github.com/ancroo/ancroo-web
```
