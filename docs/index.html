How to use

  1. Install the Ancroo Web extension and configure at least one LLM provider (the starter actions are created automatically).
  2. Select the text in a card above.
  3. Open the Ancroo side panel (toolbar icon, or Alt+Shift+Y). You can assign a custom hotkey to any action in its editor.
  4. Run the matching action — Fix Grammar, Translate to English, or Draft Reply.
