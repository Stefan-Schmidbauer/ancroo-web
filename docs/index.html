How to use

  1. Install the Ancroo Web extension and configure at least one LLM provider (the 10 starter workflows are created automatically).
  2. Select text in any field above.
  3. Open the Ancroo side panel (toolbar icon, or Alt+Shift+Y). You can assign a custom hotkey to any workflow in its editor.
  4. Pick a workflow and run it — e.g. Summarize, Translate to English, Rewrite Formal, Explain, Fix Grammar, Fix Capitalization, Draft Reply, Polite Decline, or Thank-You Note.
  5. The starter workflows either replace your selection (Translate, Rewrite, Fix Grammar, Fix Capitalization) or show the result in the side panel (Summarize, Explain, the reply workflows). Your own workflows can also insert before/after the selection or copy to the clipboard.

Manual-input workflows (like "Ask AI") don't need a selection — just open the side panel and type your text.
